# CLAUDE.md — LittleGuide

Родительский компаньон «Год за руку». Мобильное приложение на Expo. Социальный проект,
монетизации нет, выходит бесплатно в App Store и Google Play.

> ⚠️ **Приложение переписано заново 24.08.2026.** Старая веб-версия (Vite + React + Firebase)
> лежит в `legacy/` как справочник по текстам и логике — **её не чиним и не развиваем**.
> Всё, что описано ниже, относится к `mobile/`.

- План 2.0: [docs/plans/2026-08-24-littleguide-2.0.md](docs/plans/2026-08-24-littleguide-2.0.md)

## Команды

```bash
cd mobile
npm install
npx expo start        # Metro; открыть в Expo Go на симуляторе
npx tsc --noEmit      # обязательная проверка перед коммитом
```

⚠️ `xcrun simctl` и `eas build` из песочницы агента не работают — звать с отключённой песочницей,
результат сборки проверять через `eas build:list`, а не по коду возврата.

## Архитектура

```
mobile/
  app/            expo-router: (tabs)/ index·rhythm·diary·story, onboarding, capsule, settings, read/[id]
  content/        офлайн-паки в бандле: types.ts + index.ts + ru/ ua/ en/
  store/          один zustand-стор + гидрация из AsyncStorage
  i18n/           ru — источник правды, ua/en расширяют его спредом
  constants/theme.ts   две темы: «Мягкий свет» и «Тихая ночь»
  hooks/useTheme.ts    системная тема + ручное переопределение
worker/           Cloudflare Worker — прокси к Gemini (ещё не написан)
legacy/           старая веб-версия — справочник, не трогать
```

**Данные только на устройстве.** Аккаунтов нет, Firebase нет, сервера с базой нет.
Экспорт и восстановление — файлом.

**Офлайн-фундамент — жёсткое требование.** Приложение полностью работает в авиарежиме.
AI подключается ровно в трёх местах: сказка, «дай другую игру», месячное саммари дневника —
и всегда через Worker, чтобы ключ Gemini не лежал в бандле.

## Правила, которые нельзя нарушать

1. **Ритм не интерпретирует цифры.** Никаких «мало спит», «пора кормить», норм и порогов.
   Как только появляется оценка — включается Health-политика сторов. HealthKit и Google Fit
   не подключаем.
2. **Ноль медицинских заявлений.** Слова «педиатр» нет нигде — ни в промптах, ни в текстах,
   ни в описании приложения.
3. **Аудитория — родитель, не ребёнок.** Google Play Families policy ограничивает генеративный
   AI в детских приложениях, а сказки генеративные. В анкете только взрослые группы,
   Kids Category у Apple не заявляем, визуал не должен читаться как детская игра.
4. **У каждой сгенерированной сказки** — метка «сочинено ИИ» и кнопка «Пожаловаться».
5. **Никакого стрика с обнулением.** Считаем отмеченные дни в месяце; пропуск ничего не сбрасывает.
   Приложение не создаёт чувства вины — это исходное требование Вугара.

## Грабли, уже оплаченные

- **Newsreader не содержит кириллицы** — заголовки ru/ua падают в системный гротеск.
  Сериф заголовков — **Literata**. Дизайн-канвас 2.0 нарисован на Newsreader и в этой части врёт.
- **Компоненты не объявлять внутри тела экрана.** Вложенный `DateBox`/`Row` пересоздаётся
  на каждом рендере и теряет ввод в `TextInput`. Только на верхнем уровне модуля.
- **Даты форматировать языком приложения**, а не локалью телефона (`ru-RU` / `uk-UA` / `en-GB`).
- Публикация: `~/Documents/Projects/Gym-Tracker/docs/state/gym-tracker-mobile.md` — украинская
  локаль в Play называется `uk`, скриншоты в рамке iPhone для Play не годятся,
  `eas build` из песочницы даёт exit 0 без сборки и жжёт remote buildNumber.
- ⚠️ **ЕС закрыт**, пока Apple-аккаунт не мигрирует на Organization (кейс `20000141099727`).

## Стиль
Русский, коротко. Вугар — vibecoder, код не читает: визуальные изменения показывать скриншотом
с симулятора, изменения под капотом — одной строкой «что делает + как проверить».
