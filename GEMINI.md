# GEMINI.md

Инструкции для Gemini CLI при работе с проектом LittleGuide (мамапапа).

---

## Общение и стиль

Отвечай на русском, коротко и по делу. Пользователь — vibecoder: не читает код, оценивает результат **визуально** через браузер и UI.

- Визуальные изменения — показывать в браузере или скриншотом.
- Изменения "под капотом" — объяснять коротким блоком:
  ```
  ## Что изменилось
  🖥 UI  — [что видно]
  ⚙️ API — [логика/endpoint]
  ```

## Правила кодирования

1. **Минимум кода.** Только то, что решает задачу. Без спекулятивных фич и абстракций про запас.
2. **Хирургические изменения.** Трогать только нужное. Не рефакторить соседний код без запроса.
3. **Думай перед кодом.** Если задача неоднозначна — уточнить, не делать молчаливых допущений.
4. **Критерии успеха.** Перед реализацией — определить как проверим результат.

---

## Стек

Vite + React 19 + TypeScript. Firebase. Gemini API (`@google/genai`). Без Docker, без бэкенда. Данные в localStorage (`mamaPapaUser`).

---

## Команды

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run preview
```

---

## Переменные окружения

`.env.local` с ключом `GEMINI_API_KEY`. Не хардкодить, не выводить в ответы.

---

## Важно

- `getFreeAI()` — модель `gemini-3.1-flash-lite-preview` (чат, активности, квесты)
- `getPaidAI()` — модель `gemini-3.1-flash-image-preview` (генерация изображений)
- Возраст ребёнка вычисляется из `childBirthDate` в месяцах — передаётся в Gemini для персонализации.
