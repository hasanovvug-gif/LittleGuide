# Этап 8 — раздел «Передача»

Памятка для того, кто остаётся с ребёнком (партнёр, бабушка, няня). Использует уже собранные
данные ритма + постоянные инструкции родителя. Отправляется наружу одним тапом системным Share.

## Границы
- ⛔ Массив `rhythm` не трогать: ни новых полей, ни изменения формы записей.
- ⛔ Никаких сетевых вызовов, никакого AI. Раздел работает офлайн.
- ⛔ Никаких оценок и норм («мало спит», «пора кормить») — только факты из записей.
- Новый ключ верхнего уровня в `Persisted` — по прецеденту `feedType` версия схемы поднимается.

## 1. Хранилище (`store/useAppStore.ts`)

```ts
export type Handover = {
  allergies: string;   // аллергии и что нельзя
  sleep: string;       // как укладывать
  comfort: string;     // любимое / что успокаивает
  contacts: string;    // важные телефоны
  updated: number | null;
};
```

- `Persisted.handover: Handover` — добавить в тип, в `emptyState`, в `snapshot()`.
- `SCHEMA_VERSION` 3 → **4**. Комментарий рядом по образцу v2→v3: старая сборка приняла бы
  новый бэкап и молча выбросила инструкции в `normalize()`.
- `normalize()`: отсутствующий или неполный `handover` → дефолт с пустыми строками.
  Каждое поле: не строка → `''`; строка обрезается по **500 символам**; `updated` — целое
  число или `null`, будущее время → `null`.
- Новое действие `setHandover: (patch: Partial<Omit<Handover, 'updated'>>) => void` —
  мержит патч, ставит `updated: Date.now()`, персистит обычным дебаунсом.
- `PINNABLE_IDS` — добавить `'handover'`. `DEFAULT_PINNED_TABS` **не менять** (остаётся 3 плитки).

Совместимость: `inspectBackup` отбивает `schema > SCHEMA_VERSION` как `too_new` — старые
бэкапы (schema 3) читаются как есть и получают дефолтный `handover`. Отдельного кода миграции не надо.

## 2. Сборка текста (`lib/handover.ts`) — новый файл, чистая функция

```ts
export function buildHandoverText(
  args: { child: Child | null; rhythm: RhythmEvent[]; handover: Handover },
  now: number,
  t: Dict,
): string
```

Блок «Сейчас» строится ТОЛЬКО из существующих хелперов `lib/rhythm.ts`
(`sleepSummaryOfDay`, `feedingsOfDay`, `dayKey`) — своей арифметики по интервалам не писать:
- спит сейчас или нет и сколько (открытая запись `kind='sleep'`);
- последнее кормление: когда и какого типа (первое `kind='feeding'` — лента уже отсортирована по убыванию);
- итог за сегодня: сон ночью/днём и число кормлений.

Пустые поля инструкций в текст не попадают. Пустых заголовков быть не должно.
Текст читаемый в мессенджере: короткие строки, без markdown-разметки.

## 3. Экран (`app/(tabs)/handover.tsx`)

Верстать по образцу существующих экранов раздела (`sleep.tsx`), теми же компонентами и темой.
- **Сейчас** — карточка, пересчитывается по тому же живому `now`, что и Сон.
- **Инструкции** — четыре многострочных поля с подписями, сохранение при потере фокуса
  (`onBlur`), не на каждое нажатие. Под блоком — «обновлено <дата>», если `updated !== null`.
- **Кнопка «Поделиться»** — `Share.share({ message: buildHandoverText(...) })` из `react-native`.
  Отмена шаринга пользователем — не ошибка, ничего не показывать.

## 4. Плитка и навигация
- `constants/sections.ts`: `SectionId` += `'handover'`, строка в `SECTIONS`,
  группа `'daily'`, route `'/handover'`.
- Новая иконка `IconHandover` в `components/Icon.tsx` в стиле существующих.
- Маршрут объявить в `app/(tabs)/_layout.tsx` **в фиксированном порядке объявления**
  (см. решение этапа 7а: порядок вкладок задаётся объявлением, незакреплённые прячутся `href: null`).

## 5. i18n
Ключи во все три словаря — `i18n/ru.ts`, `i18n/en.ts`, `i18n/ua.ts`. Ни одного захардкоженного
русского текста в компоненте. Заголовок вкладки — `t.tabs.handover`.

## Критерии приёмки
1. `npx tsc --noEmit` — чисто.
2. `npx expo lint` — ноль ошибок.
3. Все существующие тесты проходят + **новые тесты на `buildHandoverText`**: спит/не спит,
   нет ни одной записи вообще, все инструкции пустые, кормление через полночь.
4. Бэкап, снятый прошлой сборкой (schema 3), импортируется без ошибки и даёт пустые инструкции.
5. Плитка «Передача» видна на Доме в группе «Каждый день», открывается, закрепляется долгим тапом.
